# Geek Mall Frontend

*The Vue 3 web client for a university mall coursework build.*


[English](README.md) | [简体中文](README.zh-CN.md)

**Guide:** [Status](#project-status) · [Start locally](#start-locally) · [Repository contents](#repository-contents)


This repository contains the Vue 3 web frontend for the Geek Mall coursework project. It uses Vite, Element Plus, Pinia, Vue Router and Axios.

## Project status

Course project. A live backend connection depends on the separately configured service.

## Start locally

~~~sh
npm ci
npm run dev
~~~

The project also defines npm run build and npm run preview. The frontend is a coursework codebase; a working connection to a separately configured backend depends on that environment.

## Repository contents

- src/ — application source
- public/ — static assets
- package.json and package-lock.json — scripts and pinned dependencies
